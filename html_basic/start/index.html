トルコライスとは？

トルコライスは、長崎県を代表する洋風料理で、ピラフ、トンカツ、ナポリタンの3つがワンプレートに盛られたボリューム満点の一品です。 見た目のインパクトと味の多様性が魅力で、観光客にも地元の人にも愛されています。

トルコライスの主な構成

ピラフ
バターやコンソメで味付けされたごはん。
ナポリタン
ケチャップベースの甘めのスパゲッティ。
トンカツ
サクサクに揚げられた豚カツ。時にはデミグラスソースがかけられます。

バリエーション

お店によって、トルコライスの構成はさまざまです。よく見られるアレンジには以下のようなものがあります：

  • ごはんをカレーに変更
  • パスタをミートソースに変更
  • ハンバーグを追加
  • サラダやポテト付き

なぜ「トルコ」？

名前に「トルコ」とありますが、実際にはトルコ共和国とは無関係です。

語源には諸説あり、「西洋的でエキゾチックなイメージを与えるため」といった説が有力とされています。
