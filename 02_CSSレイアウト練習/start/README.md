# 📋 CSSレイアウト集中ドリル（課題指示書）

この課題は、Webサイトでよく使われる代表的なレイアウトを **CSSのみ** を編集して作成するドリルです。
配布された `index.html` に記述されているHTMLコードは変更せず、`css/style.css` の「回答記述エリア」にCSSを追加して指定のレイアウトを完成させてください。

---

## 🏁 ドリルの進め方
1. `index.html` をブラウザで開きます（最初はバラバラな縦並びの状態です）。
2. `css/style.css` を開き、各問題に対応するコメントの下にCSSを追記していきます。
3. ブラウザを更新して、指定通りのレイアウトになっているか確認します。
4. 開発者ツール（F12）で画面幅を狭め、スマホサイズ（768px以下）にした時の表示（レスポンシブ対応）も確認してください。

## 📝 問題一覧


### 📌 問1: 横並びナビゲーションバー
ヘッダー内の「ロゴ」を左端に、「ナビゲーションメニュー」を右端に配置します。

* **使うプロパティのヒント**:
  * `display: flex;`
  * `justify-content: space-between;`
  * `align-items: center;`

---

### 📌 問2: 3カラムのカード型レイアウト
3つの商品紹介カードを横並びに配置します。テキストの量が違っても、すべてのカードの高さが揃うようにしてください。

* **使うプロパティのヒント**:
  * `display: flex;`
  * `justify-content: space-between;`（または `gap` プロパティで余白を作る）
  * 各カードの幅指定（例: `width: 30%;` や `flex: 1;` など）

---

### 📌 問3: 互い違いのレイアウト（メディアオブジェクト）
PCでは画像とテキストを交互に左右反転させて並べます。スマホでは全て「画像が上、テキストが下」の順番に並ぶように制御します。

* **使うプロパティのヒント**:
  * `display: flex;`
  * 疑似クラス `:nth-child(even)` や `:nth-of-type(even)` を使用して2つ目のアイテムを選択する
  * `flex-direction: row-reverse;` を使って左右を反転させる

---

### 📌 問4: ヒーローエリアの上下左右中央寄せ
メインビジュアルなどの背景画像があるエリアで、中身のコンテンツ（タイトルやボタンなど）を完全に真ん中（上下左右中央）に配置します。

* **使うプロパティのヒント**:
  * `display: flex;`
  * `flex-direction: column;`（中身を縦に並べる）
  * `justify-content: center;`
  * `align-items: center;`
